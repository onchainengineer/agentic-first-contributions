# Visual / No-Code Agent Builders

Drag-and-drop tools for building AI agents without writing much code. Great for contributors who want to work on frontend + AI.

## Top Picks

### [langflow-ai/langflow](https://github.com/langflow-ai/langflow)

Visual builder for LangChain flows. Python backend, React frontend.

- **Stars**: 40k+
- **Stack**: Python (FastAPI) + TypeScript (React Flow)
- **Good for**: Both backend and frontend work
- **Very active issues and PRs**

### [langgenius/dify](https://github.com/langgenius/dify)

LLMOps platform with visual workflow builder. Enterprise-friendly features.

- **Stars**: 130k+
- **Stack**: Python + TypeScript
- **Good for**: UI work, integrations, docs
- **Commercial-backed** with a large team

### [FlowiseAI/Flowise](https://github.com/FlowiseAI/Flowise)

Drag-and-drop LLM flow builder. Node.js + React.

- **Stars**: 50k+
- **Stack**: TypeScript end-to-end
- **Good for**: New nodes (each is self-contained), docs
- **Smaller team**, responsive maintainers

### [n8n-io/n8n](https://github.com/n8n-io/n8n)

Workflow automation with AI nodes. 400+ integrations.

- **Stack**: TypeScript + Vue
- **Good for**: New nodes, docs, translations
- **Extremely welcoming to contributors**

### [wandb/weave](https://github.com/wandb/weave)

LLM observability and evals from Weights & Biases. Visual UI for agent traces.

- **Stack**: Python + TypeScript
- **Good for**: Instrumentation, UI work, integrations

## Why Contribute to Visual Builders?

**Lower barrier to entry.** You can add a new node or block without understanding the whole architecture.

**Visible impact.** Users see your work in the UI directly.

**Mix of skills.** Frontend, backend, and AI all combine here.

**Rapid feedback.** These projects ship fast, so your PR gets tested quickly.

## What to Contribute

**New nodes or blocks.** Most visual builders need more nodes. Pick a service you know (Stripe, Slack, GitHub, a database) and build a node for it.

**UI improvements.** Better visualizations, better onboarding, accessibility fixes.

**Documentation.** Visual tools need good docs because the target audience is less technical.

**Templates and examples.** Pre-built agent templates save users time.

**Localization.** Many of these tools have global users but limited language support.
